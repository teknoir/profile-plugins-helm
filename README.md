# profile-plugins-helm

> **Frozen: the charts moved.** Since CI v4 P9.1 (2026-11-26) the profile plugin charts live in
> [teknoir/platform-applications-gitops `plugins/charts/`](https://github.com/teknoir/platform-applications-gitops/tree/main/plugins/charts);
> change them there by PR. `charts/` in this repo is a frozen copy at commit `edea9a9` — do not edit it.
>
> The Helm repository on `gh-pages` (https://teknoir.github.io/profile-plugins-helm) is frozen too: the
> chart-release workflow is removed, so no new chart versions are published. Every published version stays
> as-is for production (e.g. `0.0.99`) and as the staging rollback anchor (`0.0.113-p2`) — never delete or
> re-publish a version.
>
> The stunnel image (`images/stunnel`, workflow `image.yml`) is still built here.
